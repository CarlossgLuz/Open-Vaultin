# Support

Vaultin is provided as open-source software without guaranteed support or SLA.

Before requesting help:

1. run `vaultinctl doctor`;
2. confirm Python and OS versions;
3. verify the active Vaultin checkout/branch;
4. include sanitized hook errors and reproduction steps;
5. remove secrets, private repository names and personal paths.

Use the repository issue tracker for reproducible bugs and feature requests. Use the security process for vulnerabilities.
